01

Sobre o Sistema e Ambiente de Desenvolvimento

Este sistema foi desenvolvido no CentroWEG, unidade educacional do SENAI integrada ao parque fabril da WEG em Jaraguá do Sul – SC.

O algoritmo implementa uma rotina de manutenção preditiva e monitoramento industrial, processando leituras de sensores de motores instalados nos setores de Estamparia, Usinagem, Bobinagem e Pintura. O código valida a integridade dos dados, cruza os valores com parâmetros máximos/mínimos de segurança, classifica a severidade operacional (NORMAL, ATENCAO ou CRITICO) e gera automaticamente um plano de ação para a equipe de manutenção.

02

Parâmetros de Segurança (LIMITES)

A constante global LIMITES centraliza os limiares críticos de operação. Qualquer leitura que ultrapasse essas faixas dispara um alerta específico na função analisar_alertas():

temperatura_max 80.0 °C

Acima deste valor dispara alerta de Superaquecimento.

corrente_max 18.5 A

Acima deste valor dispara alerta de Sobrecorrente.

vibracao_max 4.5 mm/s

Acima deste valor dispara alerta de Vibração elevada.

rpm_min / rpm_max 1400 – 1800 RPM

Fora desta faixa dispara alerta de Rotação fora da faixa.

Lógica de Classificação de Severidade

NORMAL 0 alertas detectados — Operação estável.
ATENCAO 1 alerta detectado — Inspeção programada.
CRITICO 2 ou mais alertas — Parada imediata recomendada.

04

Arquitetura Modular: Explicação das Funções

1. validar_leitura(motor) e obter_leituras_validas(lista_motores)

Garantem a qualidade dos dados antes de qualquer cálculo. Verificam se as 7 chaves obrigatórias existem no dicionário, se nenhum valor é None e se não há grandezas físicas negativas (< 0). Retorna apenas os registros íntegros usando list comprehension.

2. analisar_alertas(motor)

Compara temperatura, corrente, vibração e RPM contra a tabela LIMITES. Acumula as descrições formatadas na lista alertas e retorna uma tupla (status, alertas) classificando o equipamento em NORMAL, ATENCAO ou CRITICO.

3. calcular_estatisticas(motores)

Agrega indicadores globais da planta utilizando sum() e max(..., key=lambda m: m["temperatura"]). Calcula temperatura média, corrente média, potência total em kW e identifica o ID do motor mais quente.

4. exibir_painel(motores)

Formata o relatório de telemetria no console com carimbo de data/hora atual via datetime.now().strftime('%d/%m/%Y %H:%M:%S'), alinhando status com {status:<7} e exibindo os alertas indentados logo abaixo de cada motor afetado.

5. gerar_plano_manutencao(motores) e exibir_manutencao(motores)

Agrupa os motores em um dicionário de prioridades ({"CRITICO": [], "ATENCAO": [], "NORMAL": []}) contendo ID, setor e quantidade de ocorrências, imprimindo a ordem de atuação para a equipe de manutenção.

Código-Fonte Completo em Python

Código original estruturado para execução direta:

from datetime import datetime

SISTEMA_NOME = "Monitoramento de Motores Industriais"
VERSAO = "1.0.0"

LIMITES = {
    "temperatura_max": 80.0,
    "corrente_max": 18.5,
    "vibracao_max": 4.5,
    "rpm_min": 1400,
    "rpm_max": 1800,
}

LEITURAS_MOTORES = [
    {"id": "MTR-01", "setor": "Estamparia", "temperatura": 68.4, "corrente": 14.2, "vibracao": 2.1, "rpm": 1750, "potencia_kw": 7.5},
    {"id": "MTR-02", "setor": "Usinagem", "temperatura": 84.7, "corrente": 19.3, "vibracao": 5.2, "rpm": 1690, "potencia_kw": 11.0},
    {"id": "MTR-03", "setor": "Bobinagem", "temperatura": 76.2, "corrente": 17.8, "vibracao": 4.7, "rpm": 1520, "potencia_kw": 5.5},
    {"id": "MTR-04", "setor": "Pintura", "temperatura": 61.0, "corrente": 11.5, "vibracao": 1.8, "rpm": 1780, "potencia_kw": 7.5},
]


def validar_leitura(motor):
    campos_obrigatorios = ["id", "setor", "temperatura", "corrente", "vibracao", "rpm", "potencia_kw"]
    for campo in campos_obrigatorios:
        if campo not in motor or motor[campo] is None:
            return False
    if motor["temperatura"] < 0 or motor["corrente"] < 0 or motor["vibracao"] < 0 or motor["rpm"] < 0:
        return False
    return True


def obter_leituras_validas(lista_motores):
    return [m for m in lista_motores if validar_leitura(m)]


def analisar_alertas(motor):
    alertas = []
    if motor["temperatura"] > LIMITES["temperatura_max"]:
        alertas.append(f"Superaquecimento ({motor['temperatura']:.1f} C)")
    if motor["corrente"] > LIMITES["corrente_max"]:
        alertas.append(f"Sobrecorrente ({motor['corrente']:.1f} A)")
    if motor["vibracao"] > LIMITES["vibracao_max"]:
        alertas.append(f"Vibracao elevada ({motor['vibracao']:.1f} mm/s)")
    if motor["rpm"] < LIMITES["rpm_min"] or motor["rpm"] > LIMITES["rpm_max"]:
        alertas.append(f"Rotacao fora da faixa ({motor['rpm']} RPM)")

    if len(alertas) == 0:
        status = "NORMAL"
    elif len(alertas) == 1:
        status = "ATENCAO"
    else:
        status = "CRITICO"

    return status, alertas


def calcular_estatisticas(motores):
    total = len(motores)
    if total == 0:
        return {}

    temp_media = sum(m["temperatura"] for m in motores) / total
    corrente_media = sum(m["corrente"] for m in motores) / total
    potencia_total = sum(m["potencia_kw"] for m in motores)
    maior_temp = max(motores, key=lambda m: m["temperatura"])

    return {
        "total_motores": total,
        "temperatura_media": round(temp_media, 2),
        "corrente_media": round(corrente_media, 2),
        "potencia_total_kw": round(potencia_total, 2),
        "motor_mais_quente": maior_temp["id"],
    }


def exibir_painel(motores):
    print("=" * 64)
    print(f"{SISTEMA_NOME} - v{VERSAO}")
    print(f"Data/Hora da leitura: {datetime.now().strftime('%d/%m/%Y %H:%M:%S')}")
    print("=" * 64)

    for motor in motores:
        status, alertas = analisar_alertas(motor)
        print(
            f"[{status:<7}] {motor['id']} ({motor['setor']}) | "
            f"Temp: {motor['temperatura']} C | Corr: {motor['corrente']} A | "
            f"Vib: {motor['vibracao']} mm/s | RPM: {motor['rpm']}"
        )
        for alerta in alertas:
            print(f"  -> Alerta: {alerta}")

    stats = calcular_estatisticas(motores)
    print("-" * 64)
    print(
        f"Resumo: {stats['total_motores']} motores | "
        f"Temp. media: {stats['temperatura_media']} C | "
        f"Corr. media: {stats['corrente_media']} A | "
        f"Potencia total: {stats['potencia_total_kw']} kW | "
        f"Maior temp.: {stats['motor_mais_quente']}"
    )
    print("=" * 64)


def gerar_plano_manutencao(motores):
    plano = {"CRITICO": [], "ATENCAO": [], "NORMAL": []}
    for motor in motores:
        status, alertas = analisar_alertas(motor)
        plano[status].append({"id": motor["id"], "setor": motor["setor"], "ocorrencias": len(alertas)})
    return plano


def exibir_manutencao(motores):
    plano = gerar_plano_manutencao(motores)
    print("\nPLANO DE MANUTENCAO PREVENTIVA:")
    print(f" - Parada imediata (CRITICO): {[m['id'] for m in plano['CRITICO']]}")
    print(f" - Inspecao programada (ATENCAO): {[m['id'] for m in plano['ATENCAO']]}")
    print(f" - Operacao estavel (NORMAL): {[m['id'] for m in plano['NORMAL']]}")


if __name__ == "__main__":
    motores_validos = obter_leituras_validas(LEITURAS_MOTORES)
    exibir_painel(motores_validos)
    exibir_manutencao(motores_validos)
